# 🎣 釣拉么 (DiaoLaMe)

> スマート釣り環境予測・戦術決定システム

[🇨🇳 中文](README.md) · [🇬🇧 English](README.en.md) · [🇰🇷 한국어](README.ko.md)

---

**釣拉么（DiaoLaMe）** は、釣り愛好家のための高品質・軽量な Web ツールです。リアルタイムの気象データと水温変動アルゴリズムを統合し、複雑な生データを直感的な 0-100 の釣り指数に変換。カスタマイズされた戦術アドバイスを提供し、出発前に「状況を把握」できるようにします。

## ✨ 主な機能

### 1. コア予測アルゴリズム（Five-Axis Matrix）
5次元加重アルゴリズムによる深度分析：

| 次元 | 重み | 説明 |
|:----|:----:|:----|
| 時間要素 | 30% | 薄明薄暮・概日リズムを分析 |
| 気圧安定性 | 20% | リアルタイム気圧変動を追跡 |
| 天候安定性 | 20% | 急な気象変動の影響をフィルタリング |
| 風況と溶存酸素 | 15% | 表層水の溶存酸素への風の影響 |
| 水温予測 | 15% | 気温傾向から水温安定性を推定 |

### 2. インタラクティブマップ（Leaflet）
- **クリーンなビジュアル**：白を基調としたミニマルな地図
- **没入型レイアウト**：端から端まで全幅表示
- **スマートフォーカス**：釣り場周辺 3km 圏を自動ズーム

### 3. 環境アラート
- **気温差警告**：7日間の気温差が 12°C を超えると赤色警告
- **動的戦術**：淡水/海水モードを自動判別、餌・水深・仕掛けを提案
- **気圧トレンド**：リアルタイム矢印表示（上昇/下降/安定）
- **月相分析**：釣行日の月齢を計算し夜間の魚情を評価

### 4. 多言語対応
- 🇨🇳 中国語 · 🇬🇧 英語 · 🇯🇵 日本語 · 🇰🇷 韓国語

## 🚀 デプロイ

### クイックスタート
`index.html` をブラウザで開くだけ。インストール不要。

### オンライン（推奨）
位置情報の精度と API セキュリティのため HTTPS 推奨：

#### Vercel（推奨）
1. GitHub リポジトリを連携
2. 自動的に静的サイトとしてデプロイ

#### GitHub Pages
1. コードをプッシュ
2. Settings → Pages で有効化

## 🎮 使い方

1. **場所を指定**：住所検索または地図をクリック
2. **設定**：淡水/海水モード切替、釣行時間を設定
3. **予測実行**：「予測開始」をクリック
4. **戦術確認**：エキスパートアドバイスを参照

## ⚠️ 免責事項

本システムが生成する予測スコアは気象アルゴリズムモデルに基づく参考情報です。実際の釣果は、現地の水質・漁獲圧・水流など様々な要因に影響されます。安全に留意し、現地の環境保護法・漁業法を遵守してください。
