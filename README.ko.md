# 🎣 钓拉么 (DiaoLaMe)

> 스마트 낚시 환경 예측 및 전술 결정 시스템

[🇨🇳 中文](README.md) · [🇬🇧 English](README.en.md) · [🇯🇵 日本語](README.ja.md)

---

**DiaoLaMe（钓拉么）** 는 낚시 애호가를 위한 고품질 경량 웹 도구입니다. 실시간 기상 데이터와 동적 수온 변화 알고리즘을 통합하여 복잡한 원시 데이터를 직관적인 0-100 낚시 지수로 변환하고 맞춤형 전술 조언을 제공합니다.

## ✨ 주요 기능

### 1. 핵심 예측 알고리즘 (Five-Axis Matrix)
5차원 가중치 알고리즘을 통한 심층 분석:

| 차원 | 가중치 | 설명 |
|:----|:----:|:----|
| 시간 요소 | 30% | 여명/황혼, 일주기 리듬 분석 |
| 기압 안정성 | 20% | 실시간 기압 변동 추적 |
| 날씨 안정성 | 20% | 급격한 기상 변화 필터링 |
| 바람 및 용존산소 | 15% | 표층수 용존산소에 대한 바람의 영향 |
| 수온 예측 | 15% | 기온 추세를 통한 수온 안정성 추정 |

### 2. 대화형 지도 (Leaflet)
- **깔끔한 비주얼**: 화이트 미니멀 지도 타일
- **몰입형 레이아웃**: 가장자리까지 꽉 차는 전폭 지도
- **스마트 줌**: 낚시 포인트 주변 3km 자동 확대

### 3. 환경 경보
- **기온차 경고**: 7일 기온차가 12°C 초과 시 적색 경고
- **동적 전술**: 담수/해수 모드 자동 전환, 미끼·수심·채비 제안
- **기압 추세**: 실시간 화살표 표시 (상승/하강/안정)
- **월상 분석**: 야간 낚시 평가를 위한 월령 계산

### 4. 다국어 지원
- 🇨🇳 중국어 · 🇬🇧 영어 · 🇯🇵 일본어 · 🇰🇷 한국어

## 🛠️ 기술 스택

| 기술 | 용도 |
|:----|:----|
| Tailwind CSS | 반응형 레이아웃 |
| Leaflet.js | 지도 엔진 |
| Open-Meteo | 기상·풍속·온도 데이터 |
| Open-Meteo Marine | 해수면 온도(SST) |
| Amap (高德) | 지오코딩 |

## 🚀 배포

### 빠른 시작
`index.html`을 브라우저에서 직접 열기만 하면 됩니다.

### 온라인 (권장)
HTTPS 환경 권장:

#### Vercel (선호)
1. GitHub 저장소 연결
2. 자동으로 정적 사이트 배포

#### GitHub Pages
1. 코드 푸시
2. Settings → Pages에서 활성화

## 🎮 사용 방법

1. **포인트 지정**: 주소 검색 또는 지도 클릭
2. **환경 설정**: 담수/해수 모드 전환, 낚시 시간 설정
3. **예측 실행**: "예측 시작" 클릭
4. **전술 확인**: 전문가 조언 참고

## ⚠️ 면책 조항

본 시스템이 생성하는 예측 점수는 기상 알고리즘 모델을 기반으로 한 참고 자료입니다. 실제 낚시 결과는 현지 수질, 어압, 수류 등 다양한 통제 불가능한 요소의 영향을 받습니다. 안전에 유의하고 현지 환경 보호 및 어업 법규를 준수하세요.
